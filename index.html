התקנהInstall

  1. פותחים את reverse.ai-mac.dmg שירד וגוררים את reverse.ai לתיקיית Applications.
  2. פותחים את האפליקציה. macOS יגיד שאי אפשר לאמת את המפתח (הבטא עוד לא חתומה): הגדרות מערכת ← פרטיות ואבטחה ← גוללים למטה ← פתח בכל זאת.
  3. חלון הגדרה יבקש הרשאה אחת (נגישות). לוחצים על הכפתור ומפעילים את reverse.ai.
  4. זהו. האפליקציה נמצאת בשורת התפריטים למעלה ועולה לבד בכניסה למחשב.
  1. Open the downloaded reverse.ai-mac.dmg and drag reverse.ai into Applications.
  2. Open it. macOS will say it can't verify the developer (this beta isn't signed yet): System Settings → Privacy & Security → scroll down → Open Anyway.
  3. A setup window asks for one permission (Accessibility). Click the button and turn on reverse.ai.
  4. That's it. It lives in the menu bar and starts by itself when you log in.
  1. מחלצים את reverse.ai-windows.zip שירד ומריצים את reverse.ai.exe.
  2. אם מופיע "Windows protected your PC" (הבטא עוד לא חתומה): More info ← Run anyway.
  3. זהו. האפליקציה נמצאת במגש המערכת (^ ליד השעון) ועולה עם ווינדוס.
  4. גרסת ווינדוס ראשונה — אם משהו לא עובד: אייקון במגש ← Open log folder ושולחים את log.txt (יש בו רק מצבים וספירות, אף פעם לא מה שהקלדתם).
  1. Unzip the downloaded reverse.ai-windows.zip and run reverse.ai.exe.
  2. If Windows shows "Windows protected your PC" (this beta isn't signed yet): More info → Run anyway.
  3. That's it. It lives in the tray (^ near the clock) and starts with Windows.
  4. First Windows build — if something misbehaves: tray icon → Open log folder and send log.txt (only states and counts, never what you typed).
