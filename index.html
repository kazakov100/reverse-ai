Where it worksאיפה זה עובד

In the apps you already type in.באפליקציות שאתם כבר מקלידים בהן.

It runs across the whole system, on Mac and Windows, not as a plugin for one app.הוא עובד בכל המערכת, במק ובווינדוס, ולא כתוסף לאפליקציה אחת.

  • Claude & Claude Code

    Prompts in Hebrew or English, in the desktop app or the terminal. Fixes are typed as keystrokes, so they work inside Claude Code too.פרומפטים בעברית או באנגלית, באפליקציה או בטרמינל. התיקון מוקלד כהקשות, אז הוא עובד גם בתוך Claude Code.

  • WhatsApp Web

    Catches the gibberish before you press Enter and send it to the group.תופס את הג׳יבריש לפני שלוחצים Enter ושולחים אותו לקבוצה.

  • Slack, Gmail, Jira, Notion

    Any text box, in the browser or in a desktop app.כל תיבת טקסט, בדפדפן או באפליקציה.

  • Terminal and IDEטרמינל ו-IDE

    Commands like git status and npm i are left alone. In a terminal it only suggests and never changes text by itself.פקודות כמו git status ו-npm i נשארות כמו שהן. בטרמינל הוא רק מציע, ואף פעם לא משנה טקסט לבד.

  • Password fieldsשדות סיסמה

    Never read. Password managers are turned off from the start.אף פעם לא נקראים. מנהלי סיסמאות כבויים מראש.

Accuracyדיוק

Measured, not promised.נמדד, לא מובטח.

Every rule is checked on text it was never tuned on: about 425,000 words of real messages, comments and sentences in both languages.כל כלל נבדק על טקסט שהוא לא כוונן עליו: כ-425,000 מילים של הודעות, תגובות ומשפטים אמיתיים בשתי השפות.

0correct words changed by itselfמילים נכונות ששונו לבד

Of 213,582 correctly typed words, none was changed automatically.מתוך 213,582 מילים שהוקלדו נכון, אף אחת לא שונתה אוטומטית.

99.4%caught by the third wordנתפס עד המילה השלישית

Lines typed on the wrong keyboard: 97.7% are flagged by the second word, 99.4% by the third.שורות שהוקלדו במקלדת הלא נכונה: 97.7% מסומנות עד המילה השנייה, 99.4% עד השלישית.

0.005%unneeded suggestionsהצעות מיותרות

On correct text, about one word in 20,000 gets a bubble you can ignore.בטקסט נכון, בערך מילה אחת מכל 20,000 מקבלת בועה שאפשר להתעלם ממנה.

Held-out test set, default settings. Wrong-keyboard typing is simulated from real text, so real use can differ. When it gets something wrong for you, a report helps fix it for everyone.סט בדיקה נפרד, בהגדרות ברירת המחדל. הקלדה במקלדת הלא נכונה מדומה מתוך טקסט אמיתי, ולכן בשימוש אמיתי התוצאות יכולות להיות שונות. כשמשהו משתבש אצלכם, דיווח עוזר לתקן את זה לכולם.

Languagesשפות

Privacyפרטיות

It reads your keyboard. Here is exactly what it does with it.הוא קורא את המקלדת שלכם. הנה בדיוק מה שהוא עושה עם זה.

A tool like this has to see what you type in order to fix it. That is a lot to ask, so the rules are strict, and you can check them.כלי כזה חייב לראות מה מקלידים כדי לתקן. זו בקשה גדולה, ולכן הכללים נוקשים, ואפשר לבדוק אותם.

Nothing you type is storedשום דבר שמקלידים לא נשמר

Only the line you are typing is kept, in memory, for up to a minute after you finish it. Nothing is written to disk.נשמרת רק השורה שמקלידים, בזיכרון, עד דקה אחרי שסיימתם אותה. שום דבר לא נכתב לדיסק.

Nothing is sent unless you send itשום דבר לא נשלח אלא אם שלחתם

The app goes online for two things: a daily check for a new version, and a report when you click Report. You see what a report holds before it goes.האפליקציה מתחברת לרשת לשני דברים: בדיקה יומית אם יש גרסה חדשה, ודיווח כשלוחצים Report. רואים מה יש בדיווח לפני שהוא נשלח.

Passwords are out of reachסיסמאות מחוץ לתחום

Password fields are never read, and password managers are excluded from the start.שדות סיסמה אף פעם לא נקראים, ומנהלי סיסמאות מוחרגים מראש.

No cloud, no clipboardבלי ענן, בלי לוח העתקה

Detection and fixes run on your computer and work offline. Fixes are typed as keystrokes, so your clipboard is never touched.הזיהוי והתיקון רצים על המחשב שלכם ועובדים גם בלי רשת. התיקון מוקלד כהקשות, ולוח ההעתקה לא משתנה.

Signed and notarizedחתום ומאומת

The Mac app is signed with an Apple Developer ID and notarized by Apple for every release.אפליקציית המק חתומה ב-Apple Developer ID ועוברת אימות של אפל בכל גרסה.

Ready for IT reviewמוכן לבדיקת IT

One page lists every permission, process and network address, with the settings a company can lock.עמוד אחד מפרט כל הרשאה, תהליך וכתובת רשת, עם ההגדרות שארגון יכול לנעול.

Installהתקנה

Set up in about a minute.התקנה בדקה בערך.

Free while in beta. You need a Hebrew keyboard and an English keyboard installed.חינם בתקופת הבטא. צריך שיהיו מותקנות מקלדת עברית ומקלדת אנגלית.

  1. פותחים את reverse.ai-mac.dmg שירד וגוררים את reverse.ai לתיקיית Applications.
  2. פותחים את האפליקציה. macOS שואל פעם אחת אם לפתוח אפליקציה שהורדה מהאינטרנט: לוחצים פתח.
  3. חלון הגדרה יבקש הרשאה אחת (נגישות). לוחצים על הכפתור ומפעילים את reverse.ai.
  4. זהו. האפליקציה נמצאת בשורת התפריטים למעלה ועולה לבד בכניסה למחשב.
  1. Open the downloaded reverse.ai-mac.dmg and drag reverse.ai into Applications.
  2. Open it. macOS asks once whether to open an app downloaded from the internet: click Open.
  3. A setup window asks for one permission (Accessibility). Click the button and turn on reverse.ai.
  4. That's it. It lives in the menu bar and starts by itself when you log in.

מק של העבודה? אם אי אפשר להפעיל את הרשאת הנגישות, שלחו ל-IT את reverseai.vercel.app/it. הם יכולים גם להתקין לכם את האפליקציה.

Company Mac? If you can't turn on Accessibility, send your IT team reverseai.vercel.app/it. They can also install it for you.

  1. מחלצים את reverse.ai-windows.zip שירד ומריצים את reverse.ai.exe.
  2. אם מופיע "Windows protected your PC" (הבטא עוד לא חתומה): More info ← Run anyway.
  3. זהו. האפליקציה נמצאת במגש המערכת (^ ליד השעון) ועולה עם ווינדוס.
  4. גרסת ווינדוס ראשונה: אם משהו לא עובד, ראו משהו לא עבד? למטה.
  1. Unzip the downloaded reverse.ai-windows.zip and run reverse.ai.exe.
  2. If Windows shows "Windows protected your PC" (this beta isn't signed yet): More info → Run anyway.
  3. That's it. It lives in the tray (^ near the clock) and starts with Windows.
  4. First Windows build: if something misbehaves, see Something off? below.

Good to knowכדאי לדעת

Questions people ask.שאלות ששואלים.

The menu is the reverse.ai icon in the menu bar (Mac) or in the tray near the clock (Windows).התפריט הוא האייקון של reverse.ai בשורת התפריטים (מק) או במגש המערכת ליד השעון (ווינדוס).

Does it catch a single word?הוא תופס גם מילה אחת?

Yes. A word typed alone on the wrong keyboard, like ,usv for תודה, gets the bubble when you pause before sending.

כן. מילה שהוקלדה לבד במקלדת הלא נכונה, כמו ,usv במקום תודה, מקבלת בועה כשעוצרים רגע לפני ששולחים.

What if it changes something it shouldn’t?ומה אם הוא משנה משהו שלא היה צריך?

Press Backspace right after an automatic fix and the line goes back to what you typed. reverse.ai then leaves that line alone.לוחצים Backspace מיד אחרי תיקון אוטומטי, והשורה חוזרת למה שהקלדתם. reverse.ai לא נוגע יותר בשורה הזו.

Can I turn it off in one app?אפשר לכבות אותו באפליקציה אחת?

Menu → Disable in … turns reverse.ai off for the app you’re in.

בתפריט ← Disable in … מכבה את reverse.ai באפליקציה שבה אתם נמצאים.

What can I change?מה אפשר לשנות?

Strict or Balanced sensitivity, Smart mode (an AI check that runs on your computer when you pause), and automatic fixes when it’s sure. All in the menu.

רגישות Strict או Balanced, Smart mode (בדיקת AI שרצה על המחשב שלכם כשעוצרים להקליד), ותיקון אוטומטי כשהוא בטוח. הכל בתפריט.

How do I get new versions?איך מקבלים גרסאות חדשות?

When a new version is out, reverse.ai tells you once. Menu → Download version…, then install it like the first time. It never installs anything by itself.

כשיוצאת גרסה חדשה, reverse.ai מודיע פעם אחת. בתפריט ← Download version…, ומתקינים כמו בפעם הראשונה. הוא אף פעם לא מתקין משהו לבד.

I’m on a company Mac. Will IT allow it?יש לי מק של העבודה. ה-IT יאשר?

Send your IT team reverseai.vercel.app/it. It lists what the app does and needs, and they can install it for you.

שלחו לצוות ה-IT את reverseai.vercel.app/it. העמוד מפרט מה האפליקציה עושה וצריכה, והם יכולים גם להתקין אותה בשבילכם.
